# 使用指南

## 快速使用

### 1. 准备协议文本

将你需要审阅的《数据保护协议 / DPA》全文准备好。建议使用纯文本格式，去除格式标记。

**脱敏建议**：提交前请替换以下信息：
- 真实公司名称 → [甲方] / [乙方]
- 具体金额 → [金额]
- 个人姓名/联系方式 → [联系人]

### 2. 发起审阅

将协议正文粘贴到对话框中，Agent 会自动启动审阅流程。

### 3. 确认审阅参数

Agent 会询问你以下信息：

| 参数 | 选项 | 说明 |
|------|------|------|
| DPA 关系类型 | 控制者→处理者 / 处理者→次处理者 / 联合控制者 / 独立控制者 | 决定审阅的义务方向 |
| 适用法规 | GDPR / UK GDPR / CCPA / PIPL / DSL / LGPD / PDPA / APP / 其他 | 可多选，决定审阅标准 |
| 你的角色 | 控制方 / 处理方 / 中立 | 决定谈判建议的方向 |
| 审阅重点 | 主体角色 / 处理范围 / 安全保障 / 跨境传输 / 权利保障 / 合同治理 | 可多选，默认全量审阅 |

### 4. 获取审阅意见书

Agent 将输出一份结构化的审阅意见书，包含：

- 风险摘要（高/中/低分级）
- 逐条风险分析与修改建议
- 缺失条款清单
- 谈判要点矩阵
- 合规检查清单
- 总体评价与签署建议

### 5. 后续交互

你可以要求 Agent：
- "详细展开第 3 条风险的分析"
- "这段建议条款帮我改成英文版"
- "如果对方拒绝修改第 5 条，我有什么替代方案？"
- "帮我检查一下这份协议是否满足 GDPR 第 28(3) 条的所有要求"

## 使用技巧

### 提高审阅质量

1. **提供完整协议**：尽量提交完整的 DPA 文本，包括所有附录和附件
2. **明确法规选择**：准确选择适用的法规，避免遗漏
3. **说明业务背景**：如适用，简要说明业务场景（如云计算服务、SaaS、数据中介等）
4. **指定审阅重点**：如有特定关注点，在提交时一并说明

### 多轮审阅

- 第一轮：全量审阅，获取整体风险概况
- 第二轮：针对高风险项深入分析
- 第三轮：生成修改后的条款措辞
- 第四轮：模拟对方可能的反驳与应对策略

### 团队协作

- 将审阅意见书导出为文档，分发给法务团队讨论
- 用审阅意见书作为内部合规培训的案例素材
- 将缺失条款清单作为协议模板优化的输入
