# 使用指南

> 使用前请先阅读 [免责声明](../DISCLAIMER.md)。本工具不构成法律意见，输出必须经合格律师复核。

---

## 1. 准备协议文本

将待审阅的《数据处理协议 / DPA》准备为纯文本，可通过三种方式录入：

- 直接粘贴到「协议正文」输入框（上限 60,000 字符）
- 上传 `.txt` / `.md` 文件
- 点击「加载示例」使用内置的虚构示例协议

**提交前请脱敏**：真实公司名称 → `[甲方]` / `[乙方]`，具体金额 → `[金额]`，个人姓名与联系方式 → `[联系人]`。协议正文会被发送到你配置的模型服务，请勿输入保密客户材料或受特权保护的内容。

---

## 2. 设置审阅参数

| 参数 | 说明 |
| --- | --- |
| DPA 关系类型 | 委托处理 / 独立控制者 / 共同控制者 / 次级处理者 / 跨境提供，决定义务方向 |
| 适用法域 | 中国 / 欧盟 / 美国，切换后展示对应的法规矩阵 |
| 法规矩阵 | 按核心法规、监管规定、国家标准等分组多选，可用「全选 / 清空」或预设组合 |
| 监管管控点 | 按监管机构分组勾选，随请求一起传给模型作为核查重点 |
| 当事方视角 | 选择你代表的一方，影响谈判建议的立场 |
| 审阅深度 | 速审（高风险速览）/ 标准（覆盖全部合规项）/ 深审（含谈判要点与法律依据）|

参数会与协议正文一起拼装为结构化提示，见 `src/app/api/audit/route.ts` 中的 `buildUserMessage`。

---

## 3. 发起与查看审阅

- 点击「开始核阅」后，意见书以流式方式逐字输出；过程中可中止。
- 左侧「风险摘要」按高 / 中 / 低统计识别到的风险。
- 右侧为 Markdown 渲染的完整审阅意见书，包含逐条批注、缺失条款、谈判要点与合规检查清单。
- 「重置」清空输入与结果，重新审阅另一份协议。

---

## 4. 提高审阅质量

1. **提供完整文本**：包含附录、附件与数据处理清单，避免遗漏关键义务。
2. **准确选择法规**：法域与关系类型选错会直接影响审阅标准。
3. **分轮审阅**：先速审定位高风险，再深审展开条款措辞与谈判策略。
4. **交叉核对**：模型引用的条文编号、生效日期与监管指南需人工查证，法规会更新，模型也可能出错。
5. **保留人工结论**：把意见书作为起草辅助与讨论底稿，不作为签署与否的唯一依据。

---

## 5. 团队协作建议

- 将输出复制到内部文档，交由法务团队逐条复核并标注采纳 / 驳回理由
- 用「缺失条款清单」反哺合同模板优化
- 脱敏后的典型案例可用于内部合规培训

---

## 常见问题

**提示「尚未配置 LLM_API_KEY」**：参见 [部署指南](deployment.md#前置条件)。

**输出中途停止或报错**：检查模型服务配额、网络与 `LLM_TIMEOUT_MS`；错误信息会直接显示在审阅窗内。

**示例与法规配置加载失败**：这两个接口读取仓库内的静态 JSON（`src/data/`），本地部署时应始终可用，失败多为服务未启动或反向代理配置问题。
